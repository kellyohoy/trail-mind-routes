# AI Route Planner

Build a web application called TrailMind AI for mountain bikers and motorcyclists. The main interface should feature an interactive split-screen: an entry form/chat drawer on the left and a large interactive map on the right. get GPS data so that initial screen shows map where user is at.

Add a feature where the user inputs a prompt like 'Rocky singletrack with high elevation gain near Chiang Mai'. Use a map rendering library to mock up a route and display an elevation graph below the map.

Add a prominent button that allows users to instantly download the generated route as a standard .gpx file so they can load it into their navigation computers.

use OpenStreetMap data as base. also add trail data from trailforks and alltrails app for reference when planning route as well as description for planned route
